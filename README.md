# Domain Tabs · 域名标签管理

Chrome 原生侧栏扩展。通过窗口 Tab 查看不同窗口，按完整域名管理所选窗口的标签页，无需构建、注册账号或配置服务。

## 安装

1. 用 Chrome 打开 `chrome://extensions/`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录 `domain-tabs`（包含 `manifest.json` 的目录）。
4. 在工具栏的拼图图标中找到 **Domain Tabs**，点击图钉固定，然后点击插件图标打开侧栏。

需要 Chrome 116 或更新版本。源码更新后，在扩展管理页点击插件卡片上的刷新按钮，并重新打开侧栏。

## 放到左边

Chrome 设置 → 外观 → 侧边栏 / 侧面板位置 → **在左侧显示**。也可以在设置中搜索「侧」。顶部设置菜单的「把侧栏放到左边」提供指引和打开外观设置的按钮。

侧栏位置是 Chrome 的全局设置，扩展 API 没有提供修改位置的接口。不同 Chrome 版本的选项名称可能略有不同。

## 功能

- 侧栏实时按完整域名聚合，`example.com` 与 `docs.example.com` 分开，协议、路径和端口不影响归类。
- 顶部搜索区固定，滚动标签列表时保持可见。
- 搜索标题、域名和网址，多个关键词需同时匹配；按 `/` 聚焦搜索，按 `Esc` 清除。
- 点击标签切换页面，悬停依次显示复制、移到新窗口、置顶和关闭按钮，已置顶标签常显置顶状态。
- 点击置顶按钮前的「复制标签」，会在同一窗口、原标签右侧新开相同网址的页面，保持当前页面不跳转；读取点击时的最新网址。
- 点击「移到新窗口」将原标签页移到新浏览器窗口并聚焦，不重新打开网址；原窗口只有该标签时可能随之关闭。
- 拖拽标签到同组另一标签的上半部或下半部，放到它的前面或后面；同步更新 Chrome 顶部顺序，搜索结果中也可操作。固定标签可在固定标签组内排序。
- 悬停域名组标题，点击图钉置顶或取消置顶。置顶组显示在整个列表最上方，最近置顶的排第一，状态保存并在各窗口同步；只调整侧栏分组顺序。
- 域名组可以收起，收起状态会保存；支持一键收起和展开全部组。
- 批量关闭域名下的标签需要确认。搜索期间只关闭当前匹配的标签；已固定、已跳转到其他域名的标签会跳过。
- 「按域名整理顶部标签」把所选窗口所有非固定标签重组为 Chrome 原生域名分组，按域名排序；现有自定义分组会被重新整理。固定标签单独显示并保留原位。
- 顶部保持紧凑：标题和统计、搜索和操作；多个窗口时增加窗口 Tab。设置按钮内提供自动整理与使用帮助。
- 设置菜单内的「自动整理顶部标签」默认关闭。开启后增量处理所有普通窗口：新标签加入已有域名组，新域名就近建组，跨域名跳转只移动该标签；同域名跳转、关闭页面不会重排全部分组。保留现有组顺序、颜色、折叠状态和自定义组。空白新标签等待加载网址后再归组，关闭开关保留已有分组。
- 支持系统深色模式。

## 权限和数据

使用 `tabs` 读取标签标题和网址并管理标签，`tabGroups` 整理原生分组，`sidePanel` 显示侧栏，`storage` 在本机保存偏好。没有网页内容注入、服务器、埋点或账号服务；页面图标直接使用标签提供的 favicon 地址。

## 验证

在本目录执行 `npm test`，不需要安装依赖。覆盖域名解析、搜索、固定标签保护、窗口隔离、原生组复用、混合域名组拆分、并发关闭和错误反馈。

手工检查：在同一窗口打开多个相同和不同域名的网页，固定一个标签，打开侧栏并搜索、切换标签，然后点击整理，检查顶部域名分组和固定标签位置。左侧显示需在正常使用的 Chrome 中设置。

## 侧栏快捷键

按 `Ctrl + Shift + E` 切换整个插件侧栏，macOS 使用 `Cmd + Shift + E`。工具栏保持显示。可以通过设置菜单的「侧栏快捷键设置」或 `chrome://extensions/shortcuts` 修改快捷键；若快捷键冲突或旧安装未自动分配，请在该页面手动设置。

Chrome 141 及以上关闭当前窗口侧栏；Chrome 116–140 使用兼容关闭方式，会同时关闭其他窗口中的本插件侧栏，随后可以再次唤起。

## 查看和清理重复标签

搜索栏右侧的双页图标可切换到重复标签视图，标出「保留」和「重复」，显示可清理数量。点击「一键清理」并确认，关闭所选窗口的多余副本；清理成功后自动返回全部标签；也可点击「返回全部」恢复正常列表。清理针对整个所选窗口，包括没有匹配搜索的重复项。

按完整网址比较，协议、路径、参数和页面锚点不同不算重复。全部已置顶标签保留；没有置顶副本时，优先保留当前活动标签，否则保留最左侧副本。存在多个已置顶副本时，清理后它们仍会显示为重复。关闭前重新检查状态，仅处理确认过的标签，不关闭新打开的标签或唯一剩余副本。

## 窗口 Tab

有多个普通浏览器窗口时，顶部显示「本窗口」「窗口 2」等 Tab 和标签数量。点击 Tab 可查看对应窗口，窗口多时横向滚动；左右方向键也可切换。只有一个窗口时隐藏此栏。提示文字展示该窗口活动页面的标题，方便辨认。

切换窗口会清除搜索并返回全部标签。搜索、统计、分组整理、拖拽排序和重复清理作用于所选窗口。点击页面会激活页面并切到它所在窗口。新建和关闭窗口后 Tab 实时更新；关闭正在查看的窗口会返回本窗口。只能查看 Chrome 扩展可访问的同一浏览器配置中的窗口。

自动整理不合并已有的同域名多组，也不按域名重新排序；需要完整归并和排序时点击「整理」。自动识别已有标题与成员域名一致的组为域名组；将其改成自定义名称后不再自动调整其中页面。

按 `Cmd + Shift + F`（其他系统 `Ctrl + Shift + F`）打开侧栏并聚焦搜索框，选中已有关键词方便替换。若未生效，在 `chrome://extensions/shortcuts` 为「打开侧栏并聚焦标签搜索框」手动分配该快捷键。
